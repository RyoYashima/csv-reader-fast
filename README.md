A faster drop-in for make.fun's csv-reader 1.0.0: `solve.js` exports `run({text, header})`, which returns exactly csv-reader's `{columns, rows, errors}` for every input (BOM, LF/CRLF, stray CRs, quote junk, unterminated quotes, short and long rows). It scans the text once by char code and takes each field as a single slice where it can, instead of building strings a character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
